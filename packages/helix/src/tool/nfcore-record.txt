Record a pipeline run in the project's provenance history (.helix/runs/).

Call this after you launch or finish a run — both the test profile and the real run — so the investigation folder keeps a re-readable record of what was done. Pass the pipeline, release, backend, mode ("test" or "run"), the exact command, the outdir, and the status ("started", "succeeded", or "failed"), plus any notes (e.g. a diagnosis if it failed).

This writes a small JSON manifest into .helix/runs/. Approvals the scientist grants are logged automatically and separately (.helix/approvals.jsonl) — you do not need to record those yourself. This is provenance bookkeeping in Helix Agent's own directory, not the scientist's data.
